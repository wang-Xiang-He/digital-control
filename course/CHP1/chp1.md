## 一、閉迴路控制系統是什麼？(1.1 Overview)

### 1. 為什麼需要「閉迴路」？

**開迴路**（open-loop）系統的輸出完全不會回頭影響輸入——就像盲目地照著食譜給定的火侯烤蛋糕，不管蛋糕實際有沒有烤熟。**閉迴路**（closed-loop，也稱回授 feedback）系統則會**量測輸出**，拿輸出（實際結果）跟「想要的結果」比較，用兩者的差異去修正輸入——就像烤蛋糕時不斷開烤箱門檢查顏色，不夠熟就再烤一下。這個「用輸出的量測值去決定輸入」的機制，就是閉迴路系統的本質：**系統的驅動訊號（輸入）至少有一部分是由系統的響應（輸出）決定的**。

### 2. 閉迴路系統的組成方塊

一個最基本的閉迴路系統（教材 Fig. 1-1）包含下列元件：

```text
期望響應 ──►(+)──► 差異訊號 ──► 補償器 ──► 受控體輸入 ──► 受控體(含致動器) ──► 響應（輸出）
              ▲(-)                                                    │
              └───────────────────── 感測器 ◄──────────────────────────┘
```

**符號與元件定義**：

| 元件 | 英文 | 功能 |
|---|---|---|
| 受控體（含致動器） | Plant (+ Control Actuator) | 真正要被控制的物理系統；致動器是驅動受控體的裝置，教材把它併入受控體方塊中一起討論 |
| 感測器 | Sensor | 量測受控體的實際響應（輸出） |
| 差異訊號（誤差） | Difference / Error Signal | 期望響應與感測器量到的實際響應之間的差 |
| 補償器 / 控制器 / 濾波器 | Compensator / Controller / Filter | 把誤差訊號「加工」成合適的受控體輸入，這個加工方式的設計正是控制系統設計者的核心工作 |

**觀念解析（為什麼不能直接把誤差訊號送進受控體？）**：教材特別強調——如果直接把「期望響應 − 實際響應」的誤差原封不動送進受控體當輸入，通常得到的閉迴路響應並不理想（可能太慢、太震盪，甚至不穩定）。因此中間一定要插入一個補償器，先把誤差訊號依照受控體的動態特性做適當的處理（放大、濾波、微分、積分…），才能得到滿意的響應——這也是為什麼「補償器設計」貫穿全書。

**例子（機長降落飛機）**：教材舉了一個生活化的例子來說明閉迴路系統的每個角色——機長手動降落飛機時，受控體是飛機本身，輸入是機長對各操縱面與速度的操作；感測器是機長的視覺與平衡感；期望響應是機長心中理想的飛行路徑；補償（控制律）則是機長根據感知到的誤差去修正操作的方式。這個例子說明了一件重要的事：**補償器的設計必須依賴受控體的動態特性**——只受過戰鬥機訓練的機長，即使操控技術純熟，也不具備安全降落大型客機的能力，因為兩種飛機的動態（受控體特性）截然不同。

### 3. 線性系統與疊加原理

本書幾乎所有分析與設計方法都只適用於**線性非時變**（linear time-invariant）離散時間系統模型，因此必須先精確定義這兩個性質。

**線性系統**（linear system）的定義是滿足**疊加原理**（principle of superposition）：若輸入 $x_1(t)$ 產生輸出 $y_1(t)$，輸入 $x_2(t)$ 產生輸出 $y_2(t)$，則對任意常數 $a_1, a_2$：

$$
\text{輸入}\ a_1x_1(t)+a_2x_2(t) \quad\Longrightarrow\quad \text{輸出}\ a_1y_1(t)+a_2y_2(t)
$$

**物理意義**：這代表系統對「加總後的輸入」的反應，恰好等於「個別輸入各自反應的加總」——沒有互相干擾、沒有交叉項。現實中所有物理系統本質上都是非線性的（例如馬達放大器有最大輸出電壓限制，超過就會飽和），但只要系統訊號的變動範圍夠小（維持在線性工作區內），系統的行為通常可以合理地用線性模型逼近。本書的分析設計方法只適用於線性系統，但書中仍會討論部分非線性效應（例如第五節伺服系統的放大器飽和）。

### 4. 非時變系統 vs. 時變系統

若系統的參數不隨時間改變，稱為**非時變系統**（time-invariant system）；反之則是**時變系統**（time-varying system）。

**例子（時變系統）**：太空載具發射時的助推段（booster stage）——燃料以已知速率被消耗，載具質量隨時間持續減少，因此描述載具動態的方程式係數（與質量相關）會隨時間改變，這就是一個時變系統的實際案例。

### 5. 離散時間系統 vs. 連續時間系統

**離散時間系統**（discrete-time system）的訊號只能在離散的時間瞬間改變數值；**連續時間**（continuous-time，也稱類比 analog）系統的所有訊號則可以隨時間連續地改變。本書的控制器（補償器）是**數位濾波器**（digital filter）——用差分方程式描述的離散時間系統，這正是第 2 章的主題。一旦決定了數位控制器要實現的轉移函數，接下來的工作就是把這個轉移函數的演算法寫成程式，放進數位電腦執行。

## 二、數位控制系統架構範例：飛機自動降落系統 (1.2)

### 1. 系統概觀

本節透過一個具體例子——**自動飛機降落系統**（與美國海軍航空母艦上實際運作的降落系統類似）——具體說明數位控制系統的結構。系統包含三大部分：**飛機、雷達單元、控制單元**。運作時，雷達量測飛機的概略垂直與水平位置並傳給控制單元；控制單元據此計算適當的**俯仰**（pitch）與**橫滾**（bank）指令，傳給飛機自動駕駛系統，驅使飛機做出對應反應。

橫向（lateral，控制水平位置）與垂直（vertical，控制高度）兩套控制系統彼此獨立（解耦，decoupled）：橫滾指令只影響水平位置，俯仰指令只影響高度。教材只詳細討論橫向控制系統。

### 2. 橫向控制系統方塊圖與取樣

$y(t)$ 是飛機相對於跑道中心延伸線的**橫向偏移距離**，控制系統的目標是讓 $y(t)\to0$。雷達每隔 $T=0.05\,\text{s}$ 量測一次 $y(t)$，因此得到取樣後的數列 $y(kT)$，$k=0,1,2,3,\dots$——這就是「取樣週期」（sample period）這個概念第一次出現的具體場景。數位控制器處理這些取樣值 $y(kT)$，計算出離散的橫滾指令 $h(kT)$。**數據保持器**（data hold，安裝在飛機上）把 $h(t)$ 夾持在最後收到的數值，直到下一個新數值送達才更新，因此橫滾指令每隔 $T=0.05\,\text{s}$ 更新一次——這正是第 3 章「取樣與重建」中零階保持器（ZOH）觀念的具體應用場景。

系統中還有兩個**擾動**（disturbances，不想要卻無法避免的輸入）：風力輸入 $w(t)$（確實會影響飛機位置），以及雷達雜訊（radar noise，因為雷達無法量測到飛機的絕對精確位置，量測值與真實值之間永遠存在誤差）。這說明**感測器雜訊在任何控制系統中都無法避免**。

**符號定義**：

| 符號 | 意義 |
|---|---|
| $y(t)$ | 飛機橫向位置（連續時間） |
| $T$ | 取樣週期（本例 $T=0.05\,\text{s}$） |
| $y(kT)$ | 第 $k$ 個取樣瞬間的橫向位置量測值 |
| $h(kT)$ | 數位控制器算出的離散橫滾指令 |
| $h(t)$ | 經數據保持器還原成連續時間的橫滾指令 |
| $w(t)$ | 風力擾動輸入 |

### 3. 完整迴路中的元件與其功能

把上面例子中的具體元件抽象化，一個典型的數位控制系統包含：

| 元件 | 功能 |
|---|---|
| 受控體 / 製程（Plant / Process） | 欲控制的物理系統，本例即飛機 |
| 控制致動器（Control Actuator） | 驅動受控體的裝置（本例為飛機自動駕駛的操縱面致動器） |
| 感測器（Sensor） | 量測受控體輸出，本例為雷達 |
| A/D 轉換器（Analog-to-Digital Converter） | 把連續時間誤差訊號轉成電腦可處理的數位形式 |
| 數位控制器（Digital Controller） | 通常由數位電腦擔任，執行數位濾波器演算法（差分方程式），依誤差算出控制指令 |
| D/A 轉換器與數據保持器（D/A Converter & Data Hold） | 把電腦算出的數位指令轉回類比訊號，並用保持器（如 ZOH）撐到下一個取樣時刻 |
| 擾動與雜訊（Disturbances & Noise） | 系統中非預期的輸入，例如風力、感測器雜訊 |

> **前置知識**：實際的 F4 戰機橫向動態模型是一個 **9 階非線性常微分方程式**（本書不會用它做例題，因為太過複雜），但教材藉此強調：真實物理系統的模型往往遠比教科書範例複雜，控制器設計必須依賴這些模型、預期的風力擾動、雷達雜訊特性、取樣週期 $T$，以及期望的響應特性——這些具體的數位控制器設計方法在第 8、9、11 章介紹。因為 9 階模型過於複雜，本書後續選用四個簡單但常見的物理系統（衛星、伺服馬達、溫控系統、電力系統）作為貫穿全書的建模範例，也就是本章第四~七節的內容。

## 三、控制問題的一般化描述與設計流程 (1.3)

### 1. 控制問題的正式描述

**控制問題**可以歸納成一句話：一個物理系統或製程，要透過**閉迴路（回授）操作**被精確地控制。輸出變數（稱為**響應**，response）依據**誤差訊號**被調整；誤差訊號則是「感測器量到的系統響應」與「期望響應」之間差異的量度。通常需要一個**控制器（濾波器）**來處理誤差訊號，以滿足下列控制準則：

| 準則 | 意義 |
|---|---|
| 干擾抑制（Disturbance Rejection） | 系統輸出應盡量不受風力、雜訊等不想要的外部擾動影響 |
| 穩態誤差（Steady-State Errors） | 系統達到穩定後，輸出與期望值之間殘留的誤差應盡量小 |
| 暫態響應（Transient Response） | 系統從一個狀態變化到另一個狀態過程中的行為（速度、震盪程度）應符合要求 |
| 對受控體參數變化的敏感度（Sensitivity） | 當受控體本身的物理參數（如摩擦係數、質量）因老化、環境等因素改變時，系統性能不應劇烈惡化 |

**觀念解析**：這四項準則會在後續章節反覆出現，是評估任何控制系統設計好壞的共同語言——例如第 6 章討論暫態響應特性、第 7 章討論穩定性、第 8～9 章的控制器設計都是圍繞這四項準則展開。

### 2. 控制系統設計的六大步驟

解決控制問題通常包含以下標準迭代流程：

1. **選擇感測器**來量測所需的回授訊號。
2. **選擇致動器**來驅動受控體。
3. **建立受控體、感測器、致動器的數學模型**（方程式）。
4. **根據建立的模型與控制準則設計控制器**。
5. **評估設計**——先用分析方法，再用電腦模擬（如 MATLAB），最後在實際物理系統上測試。
6. **反覆迭代**此流程，直到得到滿意的物理系統響應。

由於數學模型必然存在誤差，第一次在實際物理系統上測試通常不會完全滿意，控制工程師必須運用所有可用工具反覆迭代改善設計——在物理系統上實驗所累積的直覺，往往在設計過程中扮演重要角色。

### 3. 數學分析與物理系統設計之間的關係

教材用一張圖（Fig. 1-4）說明「數學方法」與「物理系統設計」之間如何銜接，這張圖也解釋了為什麼「六大步驟」需要反覆迭代：

```text
                 問題形式化 (Problem Formulation)
     物理系統 ───────────────────────────────► 系統的數學模型
   (Physical System)                        (Mathematical Model)
        ▲                                            │
        │                                            │ 概念層次的處理
        │ 解答轉譯 (Solution Translation)              │ (Conceptual Aspects：
        │                                            │  套用數學工具求解)
        │                                            ▼
        └──────────────────────────── 數學問題的解答
                                     (Mathematical Solution)
```

**觀念解析**：這張圖把控制系統設計拆成三個階段——**問題形式化**（把物理系統寫成數學模型）、**概念層次的處理**（在數學世界裡套用理論工具求解，這是本書強調的重點）、以及**解答轉譯**（把數學上的解答換回物理世界能實現的東西，例如具體的控制器參數）。教材特別指出：**實務上的主要困難通常不在數學求解本身，而在「問題形式化」與「解答轉譯」這兩個銜接物理與數學的步驟**——這也是為什麼實際設計往往需要多次繞這個迴圈才能收斂到滿意的結果。並非所有步驟都一定要走：某些系統會直接選用標準控制器架構、用實驗方式調整參數（例如工業上常見的 PID 調機），完全不建立數學模型；但太空載具這類「第一次啟動就必須成功」的系統，就沒有反覆試誤的空間，必須依賴嚴謹的數學建模與分析。

### 4. 標準負回授迴路的轉移函數（前置知識）

後續各章（尤其是第 5 章「閉迴路系統」）會大量用到單一迴路負回授系統的轉移函數公式，這裡先預告其形式，方便對照本章稍後 SMIB 範例中的閉迴路方塊圖（Fig. 1-13）：

```text
R(s) ──►(+)──► E(s) ──► Gc(s) ──► M(s) ──► Gp(s) ──► C(s)
        ▲(-)                                          │
        └───────────────── H(s) ◄──────────────────────┘
```

$$
\frac{C(s)}{R(s)} = \frac{G_c(s)G_p(s)}{1+G_c(s)G_p(s)H(s)}
$$

**符號定義：**

| 符號 | 意義 |
|---|---|
| $R(s)$ | 期望響應（參考輸入） |
| $E(s)$ | 誤差訊號 |
| $G_c(s)$ | 控制器（補償器）轉移函數 |
| $G_p(s)$ | 受控體（plant）轉移函數 |
| $H(s)$ | 感測器回授路徑的轉移函數 |
| $C(s)$ | 系統輸出 |

本章後續四個建模範例，教材的重點都放在如何推導出 $G_p(s)$——也就是這個標準迴路方塊圖中的受控體轉移函數；至於 $G_c(s)$（控制器）的設計方法，則是第 8、9、11 章的主題。

## 四、衛星系統建模 (1.4 Satellite Model)

考慮一個球形衛星的航向軸（Yaw-axis）姿態控制，透過推力器（thruster）產生轉矩來調整角度 $\theta(t)$。

### 1. 物理方程式推導

假設衛星為剛體且所處環境無摩擦（太空中沒有空氣阻力），根據牛頓第二運動定律的旋轉形式（轉矩 = 轉動慣量 × 角加速度）：

$$
J \frac{d^2 \theta(t)}{dt^2} = v(t)
$$

其中 $J$ 為衛星繞航向軸的轉動慣量，$v(t)$ 為推力器產生的轉矩。

### 2. 轉移函數 $G_p(s)$

對上式進行拉普拉斯轉換（推導轉移函數時，一律忽略初始條件；微分項 $\frac{d^2}{dt^2}$ 對應到 $s^2$）：

$$
Js^2\Theta(s) = V(s)
$$

整理可得**受控體轉移函數**（輸出對輸入的拉氏轉換比值）：

$$
G_p(s) = \frac{\Theta(s)}{V(s)} = \frac{1}{Js^2}
$$

這是一個**二階積分系統**模型——分母有兩個位於原點的極點（$s=0$ 重根），代表輸入轉矩會先被積分成角速度、再被積分成角度，沒有任何「自然阻尼」讓系統自己穩定下來（這也解釋了為什麼後面 MATLAB 模擬中，衛星系統的階躍響應會呈拋物線發散）。

### 3. 連續狀態空間模型

除了微分方程式（1-1）與轉移函數（1-3）之外，還有第三種等價的模型——**狀態空間模型**（state-variable model）。定義狀態變數 $x_1(t) = \theta(t)$ 與 $x_2(t) = \dot{\theta}(t)$（角度與角速度）：

$$
\dot{x}_1(t) = x_2(t)
$$

$$
\dot{x}_2(t) = \frac{1}{J} v(t)
$$

寫成向量矩陣形式：

$$
\begin{bmatrix} \dot{x}_1(t) \\ \dot{x}_2(t) \end{bmatrix} = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} x_1(t) \\ x_2(t) \end{bmatrix} + \begin{bmatrix} 0 \\ \frac{1}{J} \end{bmatrix} v(t)
$$

**符號定義：**

| 符號 | 意義 | 單位 |
|---|---|---|
| $\theta(t)$ | 衛星航向角（yaw angle），系統的輸出量 | rad |
| $v(t)$ | 推力器（thruster）產生的轉矩，系統的輸入量 | N·m |
| $J$ | 衛星繞航向軸的轉動慣量 | kg·m² |
| $\Theta(s)$、$V(s)$ | $\theta(t)$、$v(t)$ 各自的拉氏轉換 | — |
| $G_p(s)$ | 受控體（衛星）的轉移函數 | — |
| $x_1(t), x_2(t)$ | 狀態變數：$x_1=\theta$（角度）、$x_2=\dot\theta$（角速度） | rad、rad/s |

> **💡 觀念解析與白話文：**
> - **單位對照**：$J$ 是轉動慣量（單位 $\text{kg}\cdot\text{m}^2$），代表物體抵抗旋轉的能力；$v(t)$ 是力矩（單位 $\text{N}\cdot\text{m}$）。
> - **為什麼要有三種模型？**：微分方程式（1-1）最直接、最貼近物理定律；轉移函數（1-3）方便用拉氏轉換做頻域分析（第 6-8 章）；狀態空間模型（1-7）則是把高階微分方程降維成一階向量方程，方便電腦數值計算，也是未來把系統「離散化」寫入微控制器（第 2、4 章）的必經之路。三者描述的是同一個物理系統，只是站在不同的分析角度。

## 五、直流伺服馬達與機器人關節建模 (1.5 Servomotor System Model)

伺服系統（servo system，也就是「位置控制系統」）常見於雷達天線指向系統（antenna tracking system）或工業機器人關節。本節模型採用**電樞控制、磁場恆定**的直流馬達。

### 1. 基礎物理方程

如 Fig. 1-6 所示，馬達電樞電阻為 $R_a$、電感為 $L_a$（本模型假設電感可忽略——這是多數伺服馬達的合理近似）。

**反電動勢方程**（馬達轉動時，繞組會感應出方向與外加電壓相反的電壓，大小正比於轉速）：

$$
e_m(t) = K_b\, \omega(t) = K_b \frac{d\theta(t)}{dt}
$$

**機械平衡方程**（馬達產生的轉矩，一部分用來加速慣量 $J$，一部分被黏滯摩擦 $B$ 消耗掉，兩者之和才等於馬達輸出轉矩）：

$$
v(t) = J\frac{d^2\theta(t)}{dt^2} + B\frac{d\theta(t)}{dt}
$$

**電磁轉矩方程**（馬達產生的轉矩正比於電樞電流）：

$$
v(t) = K_T i(t)
$$

**電樞電路電壓方程**（外加電壓 = 電流流過電阻的壓降 + 反電動勢）：

$$
e(t) = i(t)R_a + e_m(t)
$$

**符號定義：**

| 符號 | 意義 | 單位 |
|---|---|---|
| $e(t)$ | 電樞（armature）輸入電壓，系統的輸入訊號 | V |
| $i(t)$ | 電樞電流 | A |
| $R_a$ | 電樞繞組電阻 | Ω |
| $L_a$ | 電樞繞組電感（本模型假設可忽略；若不能忽略，模型會變成三階） | H |
| $e_m(t)$ | 反電動勢（back EMF） | V |
| $K_b$ | 反電動勢常數：$e_m = K_b\dot\theta$ | V·s/rad |
| $K_T$ | 轉矩常數：$v = K_T i$，代表馬達的「電流換轉矩效率」——例如 $K_T=0.5\ \text{N}\cdot\text{m/A}$ 代表每通入 1 A 電流，馬達產生 0.5 N·m 的轉矩 | N·m/A |
| $v(t)$ | 馬達產生的電磁轉矩 | N·m |
| $J$ | 馬達轉軸（含負載）的總轉動慣量 | kg·m² |
| $B$ | 總黏滯摩擦係數，摩擦阻力正比於轉速 | N·m·s/rad |
| $\theta(t)$ | 馬達轉軸角度（輸出量） | rad |
| $\omega(t)$ | 馬達轉軸角速度，$\omega=\dot\theta$ | rad/s |

### 2. 消去中間變數：求出單一微分方程式

上面四個方程式描述了 $e(t)\to i(t)\to v(t)\to \theta(t)$ 的完整因果鏈，現在依序代入消去 $i(t)$ 與 $v(t)$，只留下 $e(t)$ 與 $\theta(t)$ 的關係。

先由電路方程解出電流：

$$
i(t) = \frac{e(t)-e_m(t)}{R_a} = \frac{e(t)}{R_a} - \frac{K_b}{R_a}\frac{d\theta(t)}{dt}
$$

代入電磁轉矩方程：

$$
v(t) = K_T i(t) = \frac{K_T}{R_a}e(t) - \frac{K_TK_b}{R_a}\frac{d\theta(t)}{dt}
$$

再代入機械平衡方程的左側（因為兩個式子的 $v(t)$ 是同一個物理量）：

$$
J\frac{d^2\theta(t)}{dt^2}+B\frac{d\theta(t)}{dt} = \frac{K_T}{R_a}e(t)-\frac{K_TK_b}{R_a}\frac{d\theta(t)}{dt}
$$

把含 $\dot\theta$ 的項移到左邊合併：

$$
J\frac{d^2\theta(t)}{dt^2} + \left(B+\frac{K_TK_b}{R_a}\right)\frac{d\theta(t)}{dt} = \frac{K_T}{R_a}e(t)
$$

兩邊同乘 $R_a$，得到最終的**二階微分方程式**（這是本節的核心模型，之後幾乎所有伺服系統範例都以此為基礎）：

$$
J\frac{d^2\theta(t)}{dt^2}+\left(\frac{BR_a+K_TK_b}{R_a}\right)\frac{d\theta(t)}{dt}=\frac{K_T}{R_a}e(t)
$$

### 3. 轉移函數 $G_p(s)$

對上式取拉普拉斯轉換（忽略初始條件）並解出轉移函數：

$$
G_p(s) = \frac{\Theta(s)}{E(s)} = \frac{K_T/R_a}{Js^2+\dfrac{BR_a+K_TK_b}{R_a}s} = \frac{K_T/(JR_a)}{s\left(s+\dfrac{BR_a+K_TK_b}{JR_a}\right)}
$$

**觀念解析**：這是一個「積分器串聯一階環節」的結構——分母有一個 $s=0$ 的極點（積分器，代表電壓對「角度」需要先積分成角速度才有作用）和一個 $s=-\frac{BR_a+K_TK_b}{JR_a}$ 的實極點（一階慣性環節，由摩擦與反電動勢共同決定）。書中大量範例都以這個轉移函數為基礎，因此值得熟記其結構：**積分極點來自「電壓控制角度需要先控制角速度」的物理事實，一階極點的時間常數則由電氣與機械阻尼共同決定**。

### 4. 狀態空間模型

定義 $x_1=\theta,\ x_2=\dot\theta$（角度、角速度），狀態方程如下：

$$
\begin{bmatrix} \dot{x}_1 \\ \dot{x}_2 \end{bmatrix} = \begin{bmatrix} 0 & 1 \\ 0 & -\dfrac{BR_a + K_TK_b}{JR_a} \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} + \begin{bmatrix} 0 \\ \dfrac{K_T}{JR_a} \end{bmatrix} e(t)
$$

**符號定義（補充）：**

| 符號 | 意義 |
|---|---|
| $\Theta(s)$、$E(s)$ | $\theta(t)$、$e(t)$ 的拉氏轉換 |

### 5. 應用範例一：天線指向系統（Antenna Pointing System）

**伺服機構**（servomechanism，簡稱 servo）泛指「機械位置受到控制」的系統。天線指向系統就是兩套伺服系統的組合（航向軸 yaw 與俯仰軸 pitch），這裡只討論航向軸。

系統方塊圖（Fig. 1-7(b)）為：差分放大器把「代表期望角度的電壓 $v_i$」與「代表實際角度的電壓 $v_o$（來自數位軸編碼器經 D/A 轉換）」相減得到誤差電壓 $e(t)=v_i(t)-v_o(t)$，經功率放大器放大後驅動馬達。

**非線性飽和限制**：因為誤差訊號通常功率很低，需要功率放大器才能驅動馬達，但功率放大器有最大輸出電壓限制（例如增益 5、最大輸出 24 V，則輸入超過 $24/5=4.8\,\text{V}$ 就會**飽和**）。教材特別強調：許多控制系統會刻意設計成在誤差很大時讓放大器飽和，藉此獲得最快的響應速度（用最大電壓驅動馬達以達到最大轉速）；但飽和後系統行為就不再是線性的了。本書分析設計方法只適用於線性系統，因此書中預設系統維持在線性工作區內。

### 6. 應用範例二：機器人關節（Robotic Control System）

工業機器人的每個關節都可以視為一個獨立的伺服機構來簡化分析（忽略其他關節運動的耦合效應）——雖然這種簡化在分析設計上很方便，但有時會導致關節的控制效果不夠理想。

單一機器人關節的模型（Fig. 1-9）依序串聯以下方塊：

```text
M(s) ──►[K：功率放大器]──► Ea(s) ──►[Km/(s+1)：伺服馬達]──► ωm(s) ──►[1/s：積分]──► θm(s) ──►[1/n：齒輪]──► θa(s)
```

**符號定義：**

| 符號 | 意義 |
|---|---|
| $M(s)$ | 數位電腦輸出的控制訊號 |
| $K$ | 功率放大器增益（電腦輸出訊號功率太小，無法直接驅動馬達，需要功率放大器） |
| $E_a(s)$ | 電樞電壓，用來控制手臂位置 |
| $\Theta_m(s)$ | 馬達轉軸角度 |
| $\Theta_a(s)$ | 手臂（負載）實際轉角 |
| $n$ | 齒輪減速比，$n=\Theta_m/\Theta_a$ |

**觀念解析**：$K_m/(s+1)$ 這個區塊代表「電壓到角速度」的關係（一階環節，對應上一小節馬達模型中一階極點部分），後面再串聯一個 $1/s$ 積分器把角速度變成角度——合起來就是與第 2、3 小節相同結構的二階伺服馬達模型；最後再串聯齒輪減速比 $1/n$，把馬達端角度換算成手臂端實際角度。若馬達電感不可忽略，模型會變成三階（與第 2 小節的假設一致）。

## 六、溫控系統建模 (1.6 Temperature Control System)

第三個建模範例是**熱力系統**：控制一個水槽（或艙室）內液體的溫度。液體以某流率流出，同時有溫度為 $\theta_i(t)$ 的液體流入補充；攪拌器讓槽內液體溫度均勻，維持在 $\theta(t)$；液體由電熱器加熱。

### 1. 能量守恆方程式

先定義四個熱流量：

| 符號 | 意義 |
|---|---|
| $q_e(t)$ | 電熱器供應的熱量（控制輸入） |
| $q_i(t)$ | 隨流入液體帶入的熱量（擾動） |
| $q_l(t)$ | 經由槽壁散失到環境的熱量（loss） |
| $q_o(t)$ | 隨流出液體帶走的熱量 |
| $q_s(t)$ | 儲存在液體中、使溫度上升的熱量（stored） |

根據能量守恆定律，供應的熱量必須等於儲存的熱量加上流失的熱量：

$$
q_e(t) + q_i(t) = q_l(t) + q_o(t) + q_s(t)
$$

其中儲存熱量正比於溫度上升速率（$C$ 為熱容）：

$$
q_s(t) = C\frac{d\theta(t)}{dt}
$$

流入、流出液體帶走/帶入的熱量正比於流率 $V$（假設進出流率相等且為常數）、比熱 $H$、與溫度：

$$
q_i(t) = VH\theta_i(t), \qquad q_o(t) = VH\theta(t)
$$

經槽壁散失的熱量正比於槽內外溫差、反比於熱阻 $R$（電學歐姆定律的熱學類比）：

$$
q_l(t) = \frac{\theta(t)-\theta_a(t)}{R}
$$

**符號定義：**

| 符號 | 意義 | 單位 |
|---|---|---|
| $\theta(t)$ | 艙內液體溫度，系統輸出 | °C |
| $\theta_a(t)$ | 環境（艙外）溫度，擾動輸入 | °C |
| $\theta_i(t)$ | 流入液體的溫度，擾動輸入 | °C |
| $C$ | 液體的熱容，越大代表升溫越慢 | J/°C |
| $R$ | 槽壁的熱阻，對應電阻 | °C/W |
| $V$ | 流經水槽的液體流率（假設為常數） | m³/s |
| $H$ | 液體的單位體積比熱 | J/(m³·°C) |

### 2. 完整（含擾動）的一階模型

把四個熱流量代入能量守恆方程式，並假設流率為常數 $V$（否則方程式會變成時變的）：

$$
q_e(t) + VH\theta_i(t) = C\frac{d\theta(t)}{dt} + VH\theta(t) + \frac{\theta(t)-\theta_a(t)}{R}
$$

整理成標準一階線性常微分方程式（控制輸入 $q_e(t)$，兩個擾動輸入 $\theta_i(t)$、$\theta_a(t)$，輸出 $\theta(t)$）：

$$
C\frac{d\theta(t)}{dt} + \left(VH+\frac1R\right)\theta(t) = q_e(t)+VH\theta_i(t)+\frac{\theta_a(t)}{R}
$$

對上式取拉普拉斯轉換並解出 $T(s)=\mathcal{L}[\theta(t)]$：

$$
T(s) = \frac{Q_e(s)}{Cs+VH+1/R} + \frac{VH\,T_i(s)}{Cs+VH+1/R} + \frac{(1/R)\,T_a(s)}{Cs+VH+1/R}
$$

把分子分母同除以 $\left(VH+\frac1R\right)$，整理成三個標準一階環節相加的形式（對應方塊圖 Fig. 1-11）：

$$
T(s) = \frac{K_1}{\tau s+1}Q_e(s) + \frac{K_2}{\tau s+1}T_i(s) + \frac{K_3}{\tau s+1}T_a(s)
$$

其中：

$$
\tau = \frac{C}{VH+1/R} = \frac{RC}{VHR+1}, \qquad
K_1 = \frac{1}{VH+1/R} = \frac{R}{VHR+1}, \qquad
K_2 = \frac{VH}{VH+1/R} = \frac{VHR}{VHR+1}, \qquad
K_3 = \frac{1/R}{VH+1/R} = \frac{1}{VHR+1}
$$

```text
Qe(s) ──►[ K1/(τs+1) ]──┐
Ti(s) ──►[ K2/(τs+1) ]──┼──►(+)──► T(s)
Ta(s) ──►[ K3/(τs+1) ]──┘
```

**觀念解析**：$K_1,K_2,K_3$ 三個增益的分母都相同（$VHR+1$），分子則分別是「熱阻 $R$」「$VHR$（流率相關項）」「常數 1」——這代表電熱器輸入、進流溫度擾動、環境溫度擾動三者，都是透過**同一個一階系統時間常數 $\tau$** 影響輸出溫度，只是各自的穩態增益不同。這正好呼應第三節提到的「干擾抑制」準則：控制器設計時，除了要讓 $Q_e(s)$ 通道的響應符合要求，也要考慮 $T_i(s)$、$T_a(s)$ 這兩個擾動通道對輸出的影響有多大（由 $K_2,K_3$ 決定），並設法讓閉迴路控制盡量壓低這些擾動的影響。

### 3. 忽略擾動的簡化模型（本章 MATLAB 範例採用）

若在控制系統設計初期先忽略擾動（令 $q_i(t)=0$ 且 $\theta_a(t)=0$，即忽略 $T_i(s)$、$T_a(s)$ 通道），只保留控制輸入 $Q_e(s)$ 通道，模型化簡為單輸入單輸出的一階系統：

$$
G_p(s) = \frac{T(s)}{Q_e(s)} = \frac{K_1}{\tau s+1} = \frac{K}{\tau s+1}, \qquad K=K_1=\frac{1}{VH+1/R}, \quad \tau = \frac{C}{VH+1/R}
$$

**觀念解析**：教材提醒——若忽略擾動輸入，模型是簡單的一階轉移函數；但**在控制系統設計的某個階段，擾動一定要被納入考量**，因為「使系統對擾動輸入的響應最小化」往往是控制系統設計中的一項主要規格（呼應第三節「干擾抑制」準則）。本節簡化模型也直接適用於「烤箱」或「測試艙」等空氣溫度控制系統——只要沒有外部空氣流入（$q_i(t)=0$），把液體參數換成空氣參數即可套用。

### 4. 一階滯後系統的物理直覺

$$
G_p(s) = \frac{K}{\tau s+1}
$$

> **💡 觀念解析與白話文：**
> **一階滯後（First-Order Lag）**：水槽只有熱容（儲能），沒有慣性也沒有彈簧。給定指令後溫度不會震盪，而是像爬坡一樣平滑上升，趨近穩態值 $K\times(\text{輸入})$。熱容 $C$ 越大（或散熱越慢），時間常數 $\tau$ 越大，爬升就越慢——這與衛星系統（純積分、無阻尼、發散）和伺服馬達系統（積分＋一階，會持續等速旋轉）的動態行為形成鮮明對比，三者放在一起比較，正是本章 MATLAB 範例的用意。

## 七、單機無限母線電力系統建模 (1.7 Single-Machine Infinite Bus Power System)

**單機無限母線系統**（SMIB）是分析大型電力系統中同步發電機動態特性與穩定性的標準起始模型。系統由一台同步發電機 $G$（可能代表一整個含多台同步機的大區域的等效模型）經無損傳輸線，把電力送到一個固定電壓/相位的參考點——**無限母線**（infinite bus，之所以稱為「無限」，是因為可以把它視為一台具有無窮大轉動慣量的發電機，電壓大小與相位角永遠維持不變，作為系統中其他發電機相位振盪的參考基準）。為方便計算，通常假設無限母線電壓為 1 pu、相位角為 0 度。

### 1. 非線性擺動方程式

**符號定義：**

| 符號 | 意義 | 單位 |
|---|---|---|
| $\phi(t)$ | 發電機轉子相對於同步旋轉參考軸的相位角（功角） | rad |
| $\omega(t)$ | 發電機轉子角速度 | rad/s |
| $\omega_s$ | 同步角速度（例如 60 Hz 系統為 $120\pi$ rad/s） | rad/s |
| $E$ | 發電機內部電動勢大小（視為定值） | pu |
| $x_d$ | 發電機直軸電抗 | pu |
| $x_T$ | 變壓器電抗 | pu |
| $x_l$ | 傳輸線電抗 | pu |
| $d$ | 阻尼常數 | — |
| $M$ | 發電機電機慣性常數 | — |
| $P_m$ | 由渦輪機輸入發電機的機械功率 | pu |
| $P_e$ | 發電機輸出到無限母線的電磁功率 | pu |

根據牛頓第二運動定律的旋轉形式（轉子的角速度變化率正比於輸入輸出功率的不平衡量）：

$$
\dot{\phi} = \omega-\omega_s
$$

$$
M\dot{\omega} = P_m-P_e-d\omega
$$

**物理意義**：這兩式描述「輸入機械功率與輸出電磁功率之間的不平衡，會造成發電機轉子加速或減速」——這正是電力系統動態穩定性分析的核心物理機制。

### 2. 求電磁功率 $P_e$：從電路方程式到功角關係

發電機到無限母線之間流動的複功率為：

$$
P = (Ee^{j\phi})I^*
$$

其中電流相量 $I$ 由克希荷夫定律決定（令 $x=x_d+x_T+x_l$ 為總電抗）：

$$
I = \frac{Ee^{j\phi}-1\angle0}{jx}
$$

代入化簡後，$P$ 的實部（即發電機輸出的**電磁功率** $P_e$）可以整理為：

$$
P_e = \frac{E}{x}\sin\phi
$$

**觀念解析**：這個正弦關係說明了「功角越大，輸出的電磁功率越大（在 $90°$ 之前）」，這正是電力系統中著名的**功率-功角特性曲線**（power-angle curve）的來源。

### 3. 非線性狀態方程式與線性化

代入 $P_e$，SMIB 的非線性狀態方程式為：

$$
\dot{\phi} = \omega-\omega_s, \qquad M\dot{\omega} = P_m - \frac{E}{x}\sin\phi - d\omega
$$

因為含有 $\sin\phi$ 項，這是非線性方程式。在平衡點 $(\phi_0,\omega_s)$ 附近做線性化（一階泰勒展開，小信號擾動 $\Delta\phi=\phi-\phi_0$）：

$$
\sin\phi \approx \sin\phi_0 + \cos\phi_0\cdot\Delta\phi
$$

代入並保留一次項，得到線性時不變的小信號模型：

$$
\begin{bmatrix}\dot{\Delta\phi}\\ \dot{\Delta\omega}\end{bmatrix} = \begin{bmatrix}0&1\\ -\dfrac{E\cos\phi_0}{Mx}&-\dfrac{d}{M}\end{bmatrix}\begin{bmatrix}\Delta\phi\\ \Delta\omega\end{bmatrix}+\begin{bmatrix}0\\ \dfrac1M\end{bmatrix}\Delta P_m
$$

輸出取為電磁功率的變化量：

$$
\Delta P_e = \frac{E\cos\phi_0}{x}\Delta\phi = k\Delta\phi, \qquad k \triangleq \frac{E\cos\phi_0}{x}
$$

**符號定義（補充）：**

| 符號 | 意義 |
|---|---|
| $\Delta(\cdot)$ | 表示變數相對平衡點的小信號擾動量，例如 $\Delta\phi=\phi-\phi_0$ |
| $\phi_0$ | 穩態平衡點的功角 | 
| $k$ | 線性化後的同步功率係數（synchronizing power coefficient） |

### 4. 轉移函數 $G_p(s)$ 與物理意義

對線性化的狀態方程取拉普拉斯轉換（或直接把 $\Delta\phi$ 的二階微分方程整理後取轉換），可得以 $\Delta P_m$ 為輸入、$\Delta P_e$ 為輸出的**二階轉移函數**：

$$
G_p(s) = \frac{\Delta P_e(s)}{\Delta P_m(s)} = \frac{k}{Ms^2+ds+k}
$$

**觀念解析**：

- $G_p(s)$ 在 $s=0$ 處的穩態增益為 $\dfrac{k}{k}=1$——這代表在穩態下，輸入的機械功率必須恰好等於輸出的電磁功率（能量守恆的直接體現）。
- 這是與伺服馬達（第五節，一階＋積分）和衛星系統（第四節，純積分）不同的**穩定二階系統**：分母 $Ms^2+ds+k$ 的兩個係數 $d$（阻尼）與 $k$（等效彈簧勁度）都是正值時，系統會震盪後收斂到穩定值，而不是像衛星系統一樣發散。
- 教材接著指出：雖然穩態增益已經是 1，但暫態響應（震盪程度、安定時間）不一定符合工程需求，因此仍可設計一個輸出回授控制器 $C(s)$（如 Fig. 1-13 所示的閉迴路方塊圖）來改善暫態表現，$C(s)$ 的設計必須確保閉迴路轉移函數的穩態增益仍維持為 1。這正好對應第三節介紹的標準負回授迴路公式。

> **💡 觀念解析與白話文：**
> - **功角 $\phi$（扭轉的金屬軸）**：可以把發電機與電網之間的關係想像成隔了一根有彈性的金屬軸，油門踩得越重（$P_m$ 越大），軸被扭轉的角度（功角 $\phi$）就越大。一旦功角超過 $90°$，$\sin\phi$ 開始遞減，系統就會失去同步、引發大停電——這也是為什麼電力系統穩定度分析如此重視功角的變化範圍。
> - **數學本質的統一**：線性化後系統矩陣右下角是阻尼比 $-d/M$，左下角是「電網彈簧」$-k/M$，這證明了 SMIB 系統線性化後，本質上就是與衛星、伺服馬達截然不同的**標準二階彈簧阻尼系統**（質量-阻尼-彈簧類比：$M$↔質量，$d$↔阻尼，$k$↔彈簧勁度）。

## 八、本章總結 (1.8 Summary)

本章從**閉迴路控制系統**的基本概念出發：說明了受控體、致動器、感測器、補償器如何協同運作（第一節），並用飛機自動降落系統具體示範數位控制系統的完整架構、取樣週期與擾動的概念（第二節）。接著把控制問題一般化，列出干擾抑制、穩態誤差、暫態響應、參數敏感度四項設計準則，並給出「感測器→致動器→建模→設計→評估→迭代」的六步驟流程，以及數學模型與物理系統之間「問題形式化 → 概念層次求解 → 解答轉譯」的迴路關係（第三節）。

## 九、MATLAB / Octave 實作驗證

以下程式碼將四個系統的暫態特性繪製成獨立視窗與一張綜合疊加圖，並示範標準負回授迴路公式（第三節第 4 小節）如何用 `feedback()` 對 SMIB 系統加上比例控制器，幫助你直觀理解各系統的動態差異。

```matlab
% 數位控制系統第一章：四系統動態響應比較範例
clear; clc;
set(0, 'DefaultTextFontName', 'Microsoft JhengHei');
set(0, 'DefaultAxesFontName', 'Microsoft JhengHei');

%% 1. 建立模型
J = 0.6; Gp_sat = tf([1], [J 0 0]); % 衛星 (無阻尼二階)
Ra = 2; Kb = 0.1; KT = 0.1; Jm = 0.05; Bm = 0.01;
A22 = -(Bm * Ra + KT * Kb) / (Jm * Ra); B2 = KT / (Jm * Ra);
sys_motor = ss([0 1; 0 A22], [0; B2], [1 0], 0); % 馬達 (帶阻尼一階積分)
M = 0.5; d = 0.1; k = 10; Gp_smib = tf([k], [M d k]); % 發電機 (二階穩定)
C_t = 100; R_t = 2; VH = 0.5; tau = C_t / (VH + 1/R_t); Gain = 1 / (VH + 1/R_t);
Gp_temp = tf([Gain], [tau 1]); % 溫控水槽 (一階滯後)

%% 2. 繪製終極疊加圖 (統一觀察前 50 秒)
figure('Name', '四系統無情疊加圖', 'Position', [100, 100, 1000, 600]);
t = 0:0.1:50; 
[y_sat, t_sat] = step(Gp_sat, t);
[y_motor, t_motor] = step(sys_motor, t);
[y_smib, t_smib] = step(Gp_smib, t);
[y_temp, t_temp] = step(Gp_temp, t);

plot(t_sat, y_sat, 'r', 'LineWidth', 1.5); hold on;
plot(t_motor, y_motor, 'g', 'LineWidth', 1.5);
plot(t_smib, y_smib, 'b', 'LineWidth', 1.5);
plot(t_temp, y_temp, 'm', 'LineWidth', 1.5);
grid on;

title('四個系統的階躍響應疊加圖 (觀察前 50 秒)');
xlabel('時間 (sec)');
ylabel('系統輸出');
legend('1. 衛星 (紅) - 拋物線失控', ...
       '2. 馬達 (綠) - 直線失控', ...
       '3. 發電機 (藍) - 震盪後穩定', ...
       '4. 溫控水槽 (紫) - 慢速平滑爬坡', ...
       'Location', 'northwest');

%% 3. 第三節「標準負回授迴路」示範：對 SMIB 系統加上比例控制器 C(s)=Kc
Kc = 2;                              % 比例控制器增益（對應 Fig. 1-13 的 C(s)）
Gc = tf(Kc, 1);                      % 建立控制器 C(s) = Kc
sys_closed = feedback(Gc*Gp_smib, 1); % 負回授：C(s)Gp(s) / (1+C(s)Gp(s))
figure('Name', 'SMIB 開迴路 vs 閉迴路比較');
step(Gp_smib, 'b--', sys_closed, 'k', 10);
legend('開迴路 G_p(s)', ['閉迴路 (K_c=' num2str(Kc) ')'], 'Location', 'southeast');
title('負回授控制對 SMIB 暫態響應的影響');
grid on;

disp('六張圖已成功生成！');
```
